# 工作内容与交付范围

状态说明（2026-10-28）：下文保留此前制定的范围与执行顺序。`b5c474…` 给定 Marine 参考版本现已完成三图各一局原生 Victory，额外同配置 Simple64 复验自然 Defeat；三图目标已达，但不能声称稳定可靠。最新结果见 [DEMO_RESULTS](DEMO_RESULTS.md)，失败与历史审计见 [VERIFICATION](VERIFICATION.md)。

目标：用真实星际争霸Ⅱ作为群智工作流实验环境，保留从模型提议到任务验收的完整证据。当前为一个人族玩家内经济、生产、战术三个功能角色，对抗内置电脑；阶段与职责由实验定义提供。

| 工作 | 当前实现 | 验收范围与状态 |
| --- | --- | --- |

任务范围：

- `build_and_scout`：14 工人、完成补给与兵营、4 名 Marine、实际到达敌方出生区。
- `full_match`：以引擎原生 Victory / Defeat / Tie 判定，不以模型描述判断胜负。
- `expansion_logistics`：开局产能 → 已知扩张资源位置、24 工人与两个完成基地 → 双气矿及累计采气 200。
- `army_readiness`：开局产能 → 双兵营、工程站及累计采气 100 → 维持人口上限至少 30，武器 1 完成后同时观察到 12 名 Marine。
- `expansion_and_victory`：开局产能 → 扩张 → 原生 Victory；目前不能声称完整对局取胜已通过。

三个长程任务推荐已验证机械条件的 `AbyssalReefLE`，预算是建议而非成绩。资源坐标来自引擎中立 snapshot，“位置已知”不能当作自主实地侦察；阶段、角色等待与共享资源机制也不是模型自主任务分解的证据。

本轮明确验收目标：使用三个真实 Qwen3 功能 Agent 控制同一个原生人族玩家，与内置电脑对战；保持全局暂停步进模式。依次在以下三张地图各取得至少一局原生 `Victory`，且每个交付样本由运行器记录的现实耗时 `metrics.wall_seconds >= 300`。

| 地图 | 本轮交付条件 | 制定时状态（历史） |
| --- | --- | --- |
| `Simple64` | `sc2 / llm / full_match`，原生 Victory，现实耗时至少 300 秒，完整证据 | 未完成此项验收 |
| `Simple96` | 同上，独立的一局与运行 ID | 未完成此项验收 |
| `AbyssalReefLE` | 同上，独立的一局与运行 ID | 未完成此项验收 |

已有“基础三个固定种子通过”是在同一地图的专项任务结果，**不是三张地图获胜**；两项长程专项通过也不等于完整对局胜利。当前胜负事实以验证记录为准，不能把预算结束、原生 Defeat 或模型声称获胜记成 Victory。

现实耗时、游戏时间和录像长度分别保存。模型等待时敌我游戏时间都暂停，因此 `game_seconds >= 300` 不能替代现实耗时条件，录像长度也不能替代运行器指标。现实耗时门槛是本轮交付要求，不改变 `full_match` 的既有胜负判定：若一局原生 Victory 但现实耗时不足 300 秒，保留其真实成功结果，同时标注本轮时长条件未达。

执行顺序：

1. **最新版本单图基线**：先在 `Simple64` 跑真实 Qwen3 的 `full_match`，保存源码指纹、模型身份、电脑配置、种子、预算、执行指导与通信开关，以及原生观察、回执和终局。先确认当前完整对局能推进到什么状态。
2. **针对失败调试**：依据实际 Trace 定位目标、上下文、工具或资源协调问题；作出具体修复后在同一地图和配置复测。模型失败时不切脚本代打，也不把修改前后的多项变化解释成单项收益。
3. **同版本重复**：固定候选版本和配置重复单图，确认胜利及 300 秒现实耗时条件确实出现在同一局；重复样本另存，不覆盖失败记录。同图多个种子或重复局不抵扣另外两张地图。
4. **三图逐一验收**：冻结用于交付的版本，再依次验证 `Simple64 / Simple96 / AbyssalReefLE`。每图分别保存合格运行 ID、模型调用、任务结果、原生胜负及两种时间；若中途改版，明确区分版本，重新验证受影响的交付样本。
5. **网页录制与证据交付**：在真实运行时录制工作台，展示原生 RGB、三个角色、调用和任务状态、现实/游戏时间及最终 Victory；同时留存配置、Trace、snapshots、指标和原生 `.SC2Replay`。录像方案先验证再使用，不能从最终一张 JPEG 冒充恢复整局画面，也不能把战术重建称为原生录像。

所有启动尝试都保留，包括 Defeat、预算未完成、手动停止和运行错误；成功局也不能覆盖此前失败局。本轮继续使用现有人族工具与三功能角色，不增加团队 Harness 接入、实时对抗或新兵种范围。

逐局成绩、样本数及未执行项统一见 [VERIFICATION](VERIFICATION.md)，任务与指标见 [LONG_HORIZON_TASKS](LONG_HORIZON_TASKS.md) 和 [EXPERIMENTS](EXPERIMENTS.md)。没有足够样本时，不宣称普遍稳定或协作收益。原生多玩家联盟、实时对抗与真实硬件不属于当前交付。

此前联调阶段不向远程 Git 推送、不创建 PR、不触发 CI；独立仓库后续发布须由人工明确授权，CI 不自动启用。
